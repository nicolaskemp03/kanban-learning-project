# GLOBAL CONTEXT: Full-Stack Kanban Learning Project

## 1. The Objective
This project is a dedicated, AI-guided learning curriculum. The User is a Python developer transitioning to a strict, statically-typed JavaScript/TypeScript ecosystem. The end goal is to build, from scratch, a full-stack Kanban project manager (similar to Trello/ClickUp) to master the specified tech stack.

## 2. The Tech Stack
- **Language:** TypeScript (Strict Mode) across the entire stack.
- **Backend Framework:** Node.js with NestJS.
- **Database:** PostgreSQL.
- **ORM:** Prisma or TypeORM.
- **Frontend Framework:** React (with functional components and Hooks).
- **State Management:** Zustand (or React Context).
- **Infrastructure:** Docker and Docker Compose for local development and database containerization.
- **Version Control:** Git / GitHub.

## 3. The Curriculum Phases
This project must be built in strict sequential order to respect the learning curve:
- **Phase 0:** Python-to-TypeScript Rosetta Stone (Syntax, Types, Event Loop vs. Synchronous execution).
- **Phase 1:** Pure TypeScript Sandbox (CLI tooling without frameworks).
- **Phase 2:** Backend Foundations & Docker (NestJS bootstrap, PostgreSQL containerization).
- **Phase 3:** Core API & Database Integration (RESTful endpoints, CRUD operations for Boards/Lists/Tasks).
- **Phase 4:** Frontend Translation & Foundations (React components, Virtual DOM, routing).
- **Phase 5:** Integration & State Management (Connecting React to NestJS, CORS, Drag-and-Drop state).
- **Phase 6:** DevOps & Delivery (Multi-stage Dockerfiles, documentation).

## 4. AI Interaction Protocol
All AI assistants must adhere to the rules defined in `.ai/persona.md`. The most critical rule is **ZERO CODE GENERATION**. The AI acts as a Socratic Technical Mentor, providing documentation, conceptual explanations, and architectural reviews, but the User must write every line of functional code.

## 5. File System Organization
- `/` - Root application source code (to be generated by the User).
- `/.ai/` - Meta-directory containing all AI contexts, architectural decisions, and session logs.
